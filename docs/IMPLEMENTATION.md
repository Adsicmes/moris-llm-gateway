## 1. 本文用途与边界

本文把 PRD 的已确认规则拆成可执行阶段，定义每阶段的交付物、判据、复核门禁与当前状态。它不替代技术设计文档，也不把本地测试当作上线验收。

状态分两轴，不能互相替代：

- **代码交付**：代码、配置、测试或文档已存在于提交或工作区，并完成相应范围的最小检查。
- **真实验收**：在真实实例、真实客户端宿主或真实部署环境中取得证据，并逐条满足 PRD 验收标准。
- 未接入真实实例、未在目标版本验证的行为，一律保留为“待实测”。
- 文档规则已确认不等于功能已实现；代码已提交不等于真实环境可用。

只有实际执行并留下证据（命令、日志、测试报告、截图路径）的事项，才能在“进度记录”中登记。

## 2. 职责划分

| 角色 | 责任 | 边界 |
| --- | --- | --- |
| 用户 | 确认需求规则；提供真实实例地址、账号与授权；决定是否上线 | 不代替工程验证 |
| 主模型 | 工程实现、阶段自检、组织复核、执行 git 提交、对外报告进度 | 不得在未复核时提交；不得把未实测写成通过 |
| 文档副手 | 维护 README、PRD 与实施文档，使其与实际状态和已确认规则一致 | 不改代码、不提交；不替主模型宣称完成 |
| 复核（由主模型执行） | 按阶段判据检查代码、测试与文档一致性 | 复核者与实现者可以是同一模型的不同轮次，但必须显式留下复核结论 |

职责冲突处理：文档与代码不一致时，以 PRD 的已确认规则为准，先修代码或先改文档都必须在同一阶段内说明，不能两边长期不一致。

## 3. 阶段门禁（所有阶段适用）

每个阶段结束必须依次满足：

1. **交付物齐全**：本阶段列出的代码、迁移、配置示例、测试与文档全部存在。
2. **最小验证通过**：与本阶段直接相关的静态检查或定向测试通过；没有测试覆盖的部分要写明原因。
3. **规则对照**：逐条对照 PRD 中本阶段涉及的已确认规则，列出对应实现位置。
4. **复核**：由主模型执行一次显式复核，记录发现与处理结果；未处理项不得进入下一阶段。
5. **提交**：复核通过后由主模型执行 git 提交；提交信息包含阶段编号与范围。子代理不执行提交。
6. **状态回写**：只在“进度记录”中登记实际证据，不写预期结果。

阶段可以并行准备，但不得跳过门禁直接宣称完成。真实环境未验证时，只能标记“代码已交付”，不能标记“真实验收通过”。

### P5 推理链路与失败处理

**目标**：实现 HTTP／SSE 网关入口、协议适配、统一重试与安全输出语义。

**交付物**

- 入口：模型路径解析、鉴权、请求校验、协议选择（Responses／ChatCompletions／Messages）。
- 上游适配：文本与图片输入、文本输出、工具调用、流式、推理内容、变体参数。
- 重试执行器：单次生成最多 3 次尝试（可配置），含首次、同目标重试与有序回退；有限退避与 `Retry-After`；整次 15 分钟期限。
- 可重试错误分类：连接失败、超时、429、502、503、504；认证、参数、上下文超限不盲目重试。
- 回退：仅手动有序列表，协议与能力兼容校验，记录实际命中目标。
- 输出锁定：文字／推理／工具任一送达后不重放；取消停止后续并尽力取消上游；客户端断线直接报错。
- 超时：连接 15s、首事件 120s、流空闲 90s、总期限 15min，均可配置；心跳不延长总期限。
- 生成级与 attempt 级记录。

**代码交付**：`bc6595a` 包含路由、三协议适配、SSE、重试与账本；`71b4ed8` 增加仅 SSE 上游的非流式 Responses 聚合和费用校验。本地测试通过，真实上游待测。

**真实验收**：未进行。尚未连接真实上游做流式、取消、超时与回退验证。

### P6 计价、账本、账单、汇率与订阅估算

**目标**：把金额口径落到可对账的数据结构。

**交付物**

- 价格快照：官方价、分组倍率、阶梯、缓存读写、表达式规则的插件解释结果与版本。
- 四类金额分离存储：官方价／套餐标价、API 等价消费、真实扣费、人民币实付。
- `cost = 0` 判定：仅当插件声明用户与直接供应商存在订阅付费关系；中转按量不得为 0；复杂计价采用“未表达”，不得假免费。
- 估算与对账：有 Token 与适用价才估算；真实扣费到达后替换结算口径，二者不相加；未知保持未知。
- 订阅窗口估算：六项有效条件、5% 阈值（可配置）、同采样截止；不足显示原因，不用历史或平滑。
- 人民币账单：增删改、删除确认、退款负数计入净实付、必填与可选字段、创建／修改时间。
- 汇率：1 USD → CNY 手动配置，只对新请求生效，历史快照保留，无汇率只显示原币，实付不重算。
- 时区：统计按 Asia/Shanghai，存储 UTC。

**代码交付**：`bc6595a` 包含计价与账本基础；`71b4ed8` 修正额度池归属、未知价格和账单 JSON 查询；`06281f2` 落实用户接受的 `cost: []`／价格见网关决策。

**真实验收**：未进行。尚未用真实供应商扣费记录完成估算与对账，人民币账单只完成本地流程验证。

## 9. 风险与应对

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 把本地测试当作真实验收 | 上线后出现目录、流式或授权故障 | 真实宿主与真实账号逐项留证，未取证保持“未验证” |
| Docker daemon 不可用 | 镜像、Compose、Caddy 链路未验证 | 在可用环境补构建与启动验证，不在文档中宣称通过 |
| 目标 OpenCode 版本行为与文档不一致 | 目录同步或重试关闭失效 | P4 前做最小运行时验证；不通过则调整插件方案并回写 PRD |
| OpenChamber SDK 不稳定 | 展示插件无法加载 | 保持插件独立发行，失败不影响模型同步 |
| 上游扣费延迟或缺失 | 账目不准 | 估算与对账分离，未知不记 0，保留对账状态 |
| 复杂计价无法在客户端表达 | 客户端显示偏差 | 采用“未表达”，以网关账本为准，禁止假免费 |
| 代理只覆盖推理 | 授权与刷新失败 | P4／P9 分环节验证，代理配置按能力覆盖 |
| 分组改名误判 | 目录身份错乱 | 无证据一律按删除加新增，保留历史 |
| SQLite 单实例写入竞争 | 延迟或锁等待 | WAL、短事务、批量写入；P1 定连接策略 |
| 主密钥丢失 | 上游凭据不可恢复 | 独立备份并在 P10 做恢复演练 |
